# P1 920726-1.c: real GCC and KCC hosted formatting verified

Date: 2026-11-20. This is original Batch 4 slot 7. The exact
unmodified tests/todo/generic/920726-1.c source calls two
variadic formatting functions that return different types, and
asserts that their actual formatted outputs both equal "5 20 ".
The original deliberately ignores the two returned objects, so
an original compiler PASS alone cannot validate scalar and struct
return ABI correctness.

## Real output formatting

The original has been executed with real target sprintf, strlen
and strcmp functions on four native CPU targets:

| CPU | KCC noopt | KCC opt | GCC O0 | GCC O2 |
| --- | --- | --- | --- | --- |
| PDP-6 | PASS | PASS | PASS | PASS |
| KA10 | PASS | PASS | PASS | PASS |
| KI10 | PASS | PASS | PASS | PASS |
| KS10 | PASS | PASS | PASS | PASS |

All 16 runs report rc=0, result=PASS, a SIMH HALT and a zero
guest __test_exit. All linker maps resolve real sprintf,
strlen and strcmp. The eight KCC original guest reports and
their maps are SHA256-pinned in:

    manifests/PDP10-P1-920726-HOSTED-EVIDENCE-20261120-v1.tsv
    refs/p10tk-p1-920726-hosted-evidence-20261120-v1.tar.gz

Eight GCC original and eight GCC memory-formatter guest passes
are pinned in:

    manifests/PDP10-GCC-STDIO-GUEST-EVIDENCE-20261120-v1.tsv
    refs/p10tk-gcc-stdio-guest-evidence-20261120-v1.tar.gz

The new GCC library uses GCC's real native stdarg ABI:

    $PDP10_PREFIX/pdp10-dec-none/include/stdio.h
    $PDP10_PREFIX/lib/gcc-lib/pdp10-dec-none/3.2/freestanding/libp10stdio-v1.a

It is **not** the KCC-specific sprintf entry. The GCC
production DARC archive has passed real dlink extraction,
and the normal compiler matrix now selects the installed
GCC formatter automatically; the original GCC PDP-6 O0
matrix cell independently PASSed after installation.

## Separately checked return objects

The already registered
tests/semantic/regression/pdp10-variadic-return-types-v1.c
companion passes the initialized scalar and struct return
assertions under both KCC PDP-6 profiles. All four GCC
PDP-6 compiler profiles fail at the first scalar-result
check, before reaching the returned-struct checks.
Those genuine GCC ABI bugs remain open and must not be
misreported as fixed by the new formatting library.

The verifier
tools/audit-p1-920726-hosted-closure-v1.py requires both
source-pinned suites and the independent return-value oracle.
Its host tests
tools/test-p1-920726-hosted-closure-v1.py contain 11
negative controls against falsified compiler profiles,
source changes and tampered target reports.

The P1 **testkit** obligation can now be marked covered:
the original formatting intent and previously unobserved
return-value intent both have meaningful executable checks.
It is not a claim that the GCC variadic return ABI is correct
or that the entire hosted ISO stdio library is available.

The GCC freestanding stdio implementation currently covers
only memory formatting; FILE streams and putchar/fprintf
require a real OS I/O backend. The former missing-header
diagnostics in archived Batch 4 evidence remain historical
truths, not current GCC runtime conclusions.
