# PDP10 P1: native 36-bit kdev_t encoding oracle (2026-11-19 v1)

## Original and reason for deferral

The unchanged source `tests/todo/generic/980526-2.c` is recorded in
`SEMANTIC-DEFERRED-DISPOSITION-20261118-v24.tsv` as
`width-or-source-adaptation`. Its Linux encoding splits an integer
`dev_t` into `major=dev>>8` and `minor=dev&0xff`, then packs the
major as `major<<22`. On Linux's original 32-bit unsigned-int model,
`0x12345678` encodes as `0x15800078`. On a PDP-10, `unsigned int` is
36 bits and the modulo-2^36 result instead is **`0xd15800078`**.
The upstream code also shifts a *signed* int and converts numerical
arithmetic to an arbitrary pointer; neither operation supplies a
well-defined PDP-10 numeric oracle without additional ABI constraints.

The original source and its expected literal are preserved and remain
deferred. The companion is not a silent 32-to-36-bit edit and does not
invent a hosted mknod, pointer allocation or filesystem service.

## Independent target test

`tests/semantic/regression/pdp10-kdev-36bit-encoding-v1.c` constructs
a self-contained unsigned 36-bit device encoder, preserving exactly
the original major/minor bit widths and shift count but avoiding
signed-left-shift overflow. Ten input/expected cases were generated
using Python unbounded integers with explicit modulo `2**36`:

`(((dev >> 8) << 22) | (dev & 255)) & ((1 << 36) - 1)`.

The cases include zero, minor-only values, a 1-bit major, `0xffff`,
`0x12345678`, `0xffffffff`, `0xabcdef00`, `0x80000000`, and a
36-bit-wrap-boundary example. Each input is passed through volatile
storage and its output compared to an independent numeric literal;
numbered `fail_id` values identify the first failed case.

The test is registered as a **normal semantic compiler-matrix source**
for PDP-6 native KCC optimized/unoptimized and GCC O0/O1/O2/Os.
All **six** actual PDP-6 compiler/guest executions PASS.

`tools/verify-p1-kdev36-v1.py` reconstructs the ten expected results
with host integers, checks the original upstream source SHA256 and
historical deferred status, requires all six active matrix profiles,
and checksum-verifies each original compiler/guest log in
`refs/pdp10-p1-kdev36-pdp6-20261119-v1.tar.gz` against
`PDP10-P1-KDEV36-MATRIX-RESULTS-20261119-v1.tsv`. No unsupported
compiler/profile is silently counted as an accepted test.

## Remaining P1 coverage

The original 32-bit/Linux `sys_mknod`-plus-pointer test is **not**
activated; it needs an independently justified target ABI contract if
its pointer conversion is to be reproduced. The other unresolved
width-or-source-adaptation originals include `arith-rand.c`, the
IEEE-word-layout `cbrt.c`, and the signed 52/53-bit bitfield cases;
separate companions already cover parts of the bitfield behavior.
Neither an unverified IEEE 32-bit-double overlay nor a compiler repair
is performed as part of this test-construction milestone.
